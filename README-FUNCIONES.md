# Flow Console: funciones

## Menu principal

```text
Flow Console
├─ Calendario
├─ Bandeja
├─ Añadir
├─ Corregir
├─ Publicaciones
├─ Estadísticas
└─ Automatizaciones
```

## Calendario

- Ver publicaciones, tareas y señales por día.
- Crear una publicación programada.
- Editar una publicación.
- Editar una serie completa.
- Borrar una publicación.
- Borrar una serie.
- Crear repeticiones semanales, cada 2 semanas, cada 3 semanas o mensuales.
- Usar hora local por defecto.
- Ver contador de publicaciones por día.
- Abrir Publicaciones desde una programación.
- Abrir Bandeja desde una señal.
- Abrir Automatizaciones desde una tarea.

### Libreta de notas

- Añadir notas por día.
- Editar notas.
- Ocultar o desplegar notas.
- Subir fotos en una nota.
- Ver notas sin descontrolar el tamaño del calendario.

## Bandeja

- Revisar avisos y salidas de automatizaciones.
- Leer mensajes generados por n8n.
- Abrir enlaces o formularios.
- Archivar avisos.
- Mandar avisos a papelera.
- Restaurar avisos.
- Reintentar acciones cuando esté disponible.

## Añadir

- Añadir conocimiento nuevo a la memoria.
- Pegar texto, ideas o referencias.
- Subir material.
- Clasificar material por tipo.
- Valorar utilidad.
- Definir tags, temas y estilo.
- Confirmar ingesta en RAG.

## Corregir

- Revisar memoria existente.
- Corregir etiquetas.
- Ajustar temas.
- Ajustar estilo.
- Subir o bajar peso de elementos.
- Eliminar ruido.
- Mantener la línea editorial.

## Publicaciones

- Preparar contenido para canales.
- Elegir destino.
- Editar texto de publicación.
- Añadir imagen o vídeo.
- Guardar borrador.
- Programar publicación.
- Publicar o entregar a n8n.
- Revisar diagnóstico antes de publicar.
- Ver historial.
- Recuperar publicaciones anteriores.
- Reenviar publicaciones.
- Confirmar publicado.
- Borrar historial.

### Destinos

- Instagram.
- YouTube.
- LinkedIn.
- TikTok.
- Pinterest.
- Blog.

### Generador de texto

- Generar captions.
- Adaptar texto por canal.
- Generar hashtags.
- Usar memoria editorial.
- Mandar resultado a Publicaciones.

## Estadísticas

- Registrar rendimiento mensual por canal.
- Guardar publicaciones.
- Guardar impresiones.
- Guardar interacciones.
- Guardar clics.
- Añadir canales.
- Importar datos de GA4.
- Ver usuarios activos de GA4.
- Ver sesiones con interacción.
- Ver calendario anual de rendimiento.
- Ver gráficas de evolución.

### Campaign URL Builder

- Crear URLs con UTMs para GA4.
- Definir nombre de campaña.
- Definir URL base.
- Definir source.
- Definir medium.
- Definir campaign.
- Definir content.
- Definir term.
- Generar URL.
- Guardar campaña.
- Copiar URL.
- Recuperar campaña guardada.
- Copiar campaña guardada.
- Borrar campaña guardada.

## Automatizaciones

- Ver workflows de n8n.
- Ver grupos de workflows.
- Crear grupos.
- Editar grupos.
- Asignar workflows a grupos.
- Ver detalle de workflow.
- Ver ejecuciones.
- Revisar errores.
- Refrescar estado.
- Lanzar workflows permitidos.

## Botones globales

- Atrás: vuelve a la pantalla anterior.
- Sync: recarga la vista actual.
- Salir: cierra la sesión.

## Resumen rápido

```text
Calendario = agenda y notas
Bandeja = entradas del sistema
Añadir = conocimiento nuevo
Corregir = limpiar memoria
Publicaciones = crear y publicar
Estadísticas = rendimiento, GA4 y UTMs
Automatizaciones = n8n y workflows
```
